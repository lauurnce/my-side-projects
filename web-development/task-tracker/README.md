# Mini Task Tracker: Quest Log

A retro RPG take on the Mini Task Tracker exercise. Every task is a quest. Finishing one earns XP, and every 100 XP levels you up.

## Run it

Open `index.html` in a browser. Nothing to install.

## Features

- Type a quest and press **Add Task** or hit Enter
- Click a quest or its ▸ box to complete it for +25 XP
- Fill the XP bar to level up
- **Abandon** removes a quest
- Quests and XP survive a page refresh
- **New Game** wipes everything for a fresh start
- Empty input shakes instead of adding a blank quest

## Files

- `index.html` structure
- `style.css` pixel art styling and animations
- `script.js` quest logic and saving
